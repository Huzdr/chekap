# Start-Chekap

## SYNOPSIS
Відкриває меню в консолі, щоб запускати перевірки Chekap без введення команд.

## SYNTAX

```
Start-Chekap [<CommonParameters>]
```

## DESCRIPTION
Показує у вікні PowerShell нумероване меню: 1 — усі перевірки, 2 — Система: стан ПК, 3 — Мережа, 4 — Друк, 5 — усі перевірки та звіт у файл (HTML і JSON), 6 — змінити мову (українська чи англійська), 0 — вихід. Після запуску меню показує кількість знахідок за статусами, а під нею кожну знахідку, крім «Гаразд», від найсерйозніших: статус, що знайдено, і рекомендацію. Рекомендація — це конкретна дія, а не загальна порада. Щоб повернутися до меню, натисніть Enter.

Пункт 5 зберігає звіт у папці Chekap у вашій папці «Документи», ніколи не перезаписуючи попередній звіт, і відкриває HTML-файл у браузері за замовчуванням. Пункт 6 зберігає вибрану мову командою Set-ChekapConfig, тож наступного разу меню відкриється цією мовою. Під час запуску меню бере збережену мову, а якщо її немає, мову інтерфейсу Windows.

Перевірки лише читають дані. Меню записує тільки файли звіту (пункт 5) і налаштування мови (пункт 6). Наразі жодна перевірка не потребує прав адміністратора, але з ними частина перевірок отримує більше даних, наприклад з папки з дампами аварій. Перевірка, якій вони потрібні, отримує статус Skipped, якщо PowerShell запущено без підвищення прав.

В офлайн-пакеті файл Start-Chekap.cmd лежить поруч із папкою Chekap. Двічі клацніть його, щоб запустити меню без встановлення. Меню працює від імені користувача, який увійшов у систему, і прав адміністратора не просить, тож перевірки бачать принтери, проксі-сервер і налаштування саме цього користувача. Без цих прав папку з дампами аварій прочитати неможливо: якщо вона потрібна, запустіть PowerShell від імені адміністратора й виконайте Import-Module .\Chekap\Chekap.psd1; Start-Chekap. Вікно закривається, коли ви виходите з меню.

Меню читає введення з консолі, тож потрібне інтерактивне вікно PowerShell. Коли введення закінчується, меню завершується.

## EXAMPLES

### Приклад 1: Відкрити меню
```powershell
Start-Chekap
```

Відкриває меню. Chekap має бути встановлено або імпортовано.

### Приклад 2: Запустити з розпакованого офлайн-пакета
```powershell
Import-Module .\Chekap\Chekap.psd1; Start-Chekap
```

Завантажує модуль із папки Chekap у поточному розташуванні та відкриває меню без встановлення. Саме це робить Start-Chekap.cmd.

Команда не приймає об'єктів із конвеєра.

## OUTPUTS
